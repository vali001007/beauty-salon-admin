# AI 智能体与问数能力文档索引

本目录按版本定位和当前主线整理历史方案、开发记录、验收材料与独立实验，避免把已冻结的设计和正在运行的 Ami Brain 主线混在一起。

## 阅读顺序

1. `07-Ami-Brain-当前主线/`：当前产品主线、发布证据、能力规划与历史归档。
2. `01-Agent-V1与早期架构/` 至 `06-Agent-V6/`：已完成或冻结的历史版本资料，供追溯，不作为新功能默认入口。
3. `08-跨版本对比/`：版本差异、替代关系和治理决策。
4. `09-独立实验/`：未纳入当前主线的独立探索。

## 维护规则

- 新的业务能力、发布门禁和产品验收资料优先归入 `07-Ami-Brain-当前主线/`。
- 历史资料保留原文件名和日期；移动时同步检查引用，避免断开决策与验收链路。
- 版本定位、替代关系和主入口以当前主线治理文档为准，不以历史方案标题推断。
- 自动生成的中间测试结果不应与稳定的方案、题库、最终验收结论混放；仅保留能够复现当前 Release 结论的正式输入和摘要。
