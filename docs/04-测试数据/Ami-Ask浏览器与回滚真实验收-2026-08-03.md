### 7.4 客户消费排行回归

浏览器验收问题：`消费金额最高的客户前10名`。

首次实测发现 SQL 错误使用 `customer_count` 排序，无法证明“消费金额最高”。修复后查询按 `SUM(total_paid_amount) DESC` 排序，前五项为 186301、185855、180923、178188、175333，严格递减。客户姓名仍为脱敏值，未显示手机号。

审计 SQL 使用：

```sql
SELECT customer_id, customer_name_masked,
       COUNT(DISTINCT customer_id) AS customer_count,
       SUM(total_paid_amount) AS total_paid_amount
FROM ask_data_customer_profile_summary_view
WHERE ask_data_customer_profile_summary_view.store_id = ANY(:allowedStoreIds)
GROUP BY customer_id, customer_name_masked
ORDER BY total_paid_amount DESC
LIMIT 10;
```
